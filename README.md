# Task Manager (Менеджер задач)

## 📖 Назначение программы
Консольное приложение для управления списком задач. Программа позволяет добавлять новые задачи и просматривать текущий список. 
Проект создан в учебных целях для изучения основ языка Java и системы контроля версий Git.

## ☕ Используемая версия Java
Проект написан и протестирован на **Java 24** (Oracle OpenJDK). 
Рекомендуется использовать версию 24 или новее.

## 🚀 Инструкция по запуску

### Способ 1: Запуск через среду разработки (IntelliJ IDEA)
1. Откройте проект в IntelliJ IDEA.
2. В левом меню (Project) откройте каталог `src` -> `main` -> `java` -> `org.example`.
3. Дважды кликните на файл `Main.java`.
4. Нажмите зеленую стрелочку (Run) рядом с методом `public static void main` (или нажмите `Shift + F10`).
5. Следуйте инструкциям в консоли (терминале).

### Способ 2: Запуск через терминал (Командная строка)
Если у вас установлен JDK, вы можете запустить программу из терминала:

```bash
# Перейти в папку с проектом
cd путь/к/вашему/проекту

# Скомпилировать файл
javac src/main/java/org/example/Main.java

# Запустить программу
java -cp src/main/java org.example.Main
